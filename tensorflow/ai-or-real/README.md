# Real or AI? Detecting AI-generated images

A deep learning app that tells real photos from images generated by Stable Diffusion,
built with TensorFlow/Keras and Streamlit.

**Live demo:** [add your Streamlit link here](https://your-app.streamlit.app)

It goes further than "upload an image, get a label": it shows **where** the model looked
(Grad-CAM), how its answer **changes under JPEG compression**, and a **model card** with
test results and honest limitations.

## What the app does

| Tab | What it shows |
|---|---|
| **Analyse** | Upload an image or take a photo. The model's verdict, its confidence, the 32×32 version it actually sees, and a Grad-CAM heatmap of the regions that drove the decision. |
| **Batch** | Analyse many images at once; results table, counts, thumbnail grid and CSV download. |
| **Compare models** | The small CNN and MobileNetV2 side by side on the same image, each with its own heatmap. |
| **Stress test** | Re-compresses an image from JPEG quality 100 down to 10 and charts how the probability of "AI-generated" moves, flagging the quality at which the verdict flips. |
| **Model card** | Test metrics, robustness table, confusion matrix, training curves and limitations. |

A sidebar sets the model, the decision threshold and the heatmap strength.

## Data

[CIFAKE](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images)
(Bird & Lotfi, 2024): 60,000 real images from CIFAR-10 and 60,000 images generated with
Stable Diffusion 1.4 to match the same ten classes. All images are 32×32 pixels.

- Training: 100,000 images, of which 10% are held out as a validation set.
- Testing: 20,000 images, used only once for the final evaluation.

## Method

**Small CNN (from scratch).** Three convolutional blocks (32 → 64 → 128 filters, two 3×3
convolutions each, max pooling, dropout 0.25), global average pooling, a 128-unit dense layer
with dropout 0.5, and a sigmoid output. Adam, learning rate 1e-3.

**MobileNetV2 (transfer learning).** ImageNet-pretrained MobileNetV2, input upscaled from
32×32 to 96×96, fine-tuned end to end with a new sigmoid head. Adam, learning rate 1e-4.

**Both:** binary cross-entropy, horizontal-flip augmentation, the checkpoint with the best
validation accuracy is kept, and training stops early if validation accuracy stops improving
for 3 epochs. Decoded images are cached in memory to make CPU training practical.

**Explainability.** Grad-CAM on the last convolutional feature map (inside the backbone for
MobileNetV2).

**Robustness.** The test set is re-encoded as JPEG at quality 90, 70 and 50, because images
shared online are almost always re-compressed.

## A bug worth explaining

My first small CNN scored about **90% on training data but 59% on the test set**, and once
predicted "Real" for all 20,000 test images. The cause was BatchNormalization: during training
it normalises each batch with that batch's own statistics, but at test time it switches to
running averages that, on short CPU runs, had not caught up. The model was effectively a
different network at test time.

The fix: remove BatchNormalization from the small CNN, and call the pretrained MobileNetV2
backbone with `training=False` so its normalisation layers stay in inference mode while its
weights are fine-tuned (the approach Keras recommends for transfer learning). After the fix,
training and validation accuracy track each other closely.

## Limitations

- The models only ever saw **32×32** images; uploads are shrunk to 32×32 before prediction,
  which throws away most of the detail in a modern photo.
- Every fake in CIFAKE comes from **one generator, Stable Diffusion 1.4**. Images from newer
  generators (Midjourney, DALL·E 3, Gemini, Flux) can be classified as real.
  [Add your own test here, e.g. "On 10 images from Gemini it was right on X/10."]
- High accuracy on CIFAKE does not mean the model detects AI-generated images in general:
  it may have learned patterns specific to one generator and one image size.

## Run it yourself

```
pip install tensorflow numpy pandas pillow matplotlib scikit-learn streamlit

# Train and evaluate (needs the CIFAKE folder with train/ and test/)
python cifake_tensorflow.py --data-dir cifake
python cifake_tensorflow.py --data-dir cifake --backbone mobilenet --epochs 5

# Start the app
streamlit run app_tensorflow.py
```

Training saves the models to `models_tf/` and the test results to `results_tf/`, which the
app reads.

## Project structure

```
cifake_tensorflow.py   data loading, both models, training and evaluation
app_tensorflow.py      the Streamlit app
models_tf/             trained models (.keras)
results_tf/            metrics, confusion matrices and training history
requirements.txt       packages for deployment
```
